User:
How can I set the values of a column in a polars dataframe to NA where a boolean mask column is true

Claude:
Use `when/then/otherwise` — the branch that isn't taken defaults to null, so you can just leave it out:

```python
import polars as pl

df = pl.DataFrame({"x": [1, 2, 3, 4], "mask": [False, True, False, True]})

df = df.with_columns(
    pl.when(pl.col("mask")).then(None).otherwise(pl.col("x")).alias("x")
)
```

Or flip the condition and drop `otherwise` entirely, which does the same thing more compactly:

```python
df.with_columns(pl.when(~pl.col("mask")).then(pl.col("x")).alias("x"))
```

A couple of notes:

- **Keep the alias.** Without `.alias("x")` you get a new column named after the condition rather than an in-place replacement.
- **Dtype.** `then(None)` normally resolves to the dtype of the other branch, but if you hit a supertype complaint (common with nested or temporal types), be explicit: `.then(pl.lit(None, dtype=pl.Int64))`.
- **Several columns at once:**

```python
cols = ["x", "y", "z"]
df.with_columns(
    pl.when(pl.col("mask")).then(None).otherwise(pl.col(cols)).name.keep()
)
```

`name.keep()` preserves each original column name so they're replaced rather than appended.

No R in this container, so I couldn't render it — read the code with that in mind. Two notes before it: your data are already aggregated counts over a nominal variable, so this is a bar chart of summed counts rather than a histogram (a histogram bins a continuous variable, and there's nothing continuous here). And `na.rm = TRUE` silently drops the seven suppressed cells, which sit in four different causes.

````quarto
```{r}
#| label: fig-cause
#| fig-cap: "Deaths of people experiencing homelessness in Toronto by cause of death, 2022 to 2024. Acute drug toxicity accounts for more deaths than all other identified causes combined. Cells with counts too small to publish are suppressed and excluded."
#| echo: false
#| warning: false

cause_counts <-
  analysis_data |>

  )

cause_counts |>
  ggplot(aes(x = deaths, y = Subgroup, fill = highlight)) +
  geom_col(width = 0.7) +
  geom_text(
    aes(label = paste0(deaths, " (", round(share), "%)")),
    hjust = -0.15,
    size = 3.1,
    colour = "grey25"
  ) +
  scale_fill_manual(
    values = c("TRUE" = "#2166AC", "FALSE" = "#8C8C8C"),
    guide = "none"
  ) +
  scale_x_continuous(expand = expansion(mult = c(0, 0.2))) +
  labs(x = NULL, y = NULL) +
  theme_minimal(base_size = 11) +
  theme(
    panel.grid = element_blank(),
    axis.text.x = element_blank(),
    axis.ticks = element_blank()
  )
```
````

On the choices, since a few are load-bearing for the "far and away" point:

**Sorted horizontally.** `fct_reorder` sorts bars by count, so the ranking is readable without the eye doing any work, and horizontal bars let the eight cause labels sit flat instead of rotated. The gap between the top bar and the second is the whole message, and sorting puts them adjacent.

**One highlighted colour, the rest grey.** Colour here is emphasis, not identity — each bar is already labelled, so the blue adds nothing except *look here*. That means no legend, which is correct: a legend mapping blue to "acute drug toxicity" when the bar is labelled "Acute Drug Toxicity" is pure noise. The grey is `#8C8C8C` rather than something lighter so the non-highlighted bars survive printing; against a white page it clears 3:1 contrast, and the blue-grey pair stays distinguishable under protanopia and tritanopia.

**Labels instead of an x-axis.** With eight bars, printing the count and share on each is more precise than an axis and a gridline sweep, so I dropped the axis text, ticks, and grid entirely. The share in parentheses is what actually carries "far and away" — 55% next to 13% does more than bar length alone.

Two things to check once you knit:

The long cause labels ("Cardiovascular Disease", "Unintentional Injury") plus the value labels may crowd at default figure width. If they collide, add `fig-width: 6.5` and `fig-height: 3.5` to the chunk options rather than shrinking the text.

If you want the caption's claim to be literally true, verify it: 457 against 825 total means acute drug toxicity exceeds all other causes combined only if you count pending and unknown as non-causes (457 vs 368 identified-plus-unidentified). Against *identified* causes alone — excluding the 142 pending and unknown — it's 457 vs 226, comfortably more than double. Tighten the caption to "than all other identified causes combined" as written above, or recompute inline if you'd rather state it against the full total.


Tinting both `panel.background` and `plot.background` is what makes it read as a deliberate block rather than a stray grey rectangle — if you tint only the panel, the cause labels sit on white outside it and the whole thing looks misaligned. The thin `grey85` outline on `plot.background` defines the edge, and the margin keeps the labels off it.

**Why `#F4F4F2` specifically, and the ceiling on how dark you can go.** Contrast is measured against whatever the mark sits on, so darkening the backdrop eats into the grey bars' contrast. At `#F4F4F2` both bar colours still clear 3:1. One step darker, at `#EFEFEC`, the grey bars fall to 2.92:1 and drop below the floor — which in practice means the non-highlighted bars start to muddy into the panel on a printed page, exactly the failure you're trying to avoid in the other direction.

If `#F4F4F2` is too subtle for what you want, don't just darken the panel — darken the bars with it. `#1A4F86` and `#6E6E6E` on a `#EAEAE6` panel keeps everything above 3:1 and stays distinguishable under protanopia and tritanopia. It's a heavier look, and the blue goes slightly darker than ideal for a mark, but it's a legitimate trade if you want the figure to sit more firmly on the page.

One thing to confirm when you knit: `plot.background` fills the full figure region, so if you've set `fig-width` wider than the text block the tinted rectangle will extend past your margins and look wrong. Set `fig-width: 6.5` to match a standard LaTeX text width.
